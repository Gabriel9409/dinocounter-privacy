# DinoCounter Privacy Policy

**Effective date: September 29, 2026**  
**Last updated: September 29, 2026**

DinoCounter is a scientific counting and data-management application developed by Gabriel L. Rojas Abrahantes and published under the Google Play developer account name **Rojas Digital Labs**.

This Privacy Policy explains how DinoCounter handles information when you use the application.

## 1. Data collection

DinoCounter does not require users to create an account, sign in, or provide personal information in order to use the application.

DinoCounter does not intentionally collect, transmit, or store user data on servers operated by the developer.

The application does not currently use:

- advertising SDKs;
- analytics services;
- behavioral tracking;
- cloud accounts;
- remote user databases;
- third-party crash-reporting services.

Scientific information entered by the user, including project information, sample metadata, counting results, technical replicates, notes, and related scientific records, is stored locally on the user's device.

## 2. Scientific and user-entered data

DinoCounter is designed to allow users to record and manage scientific data.

Information entered into free-text fields or project records is determined entirely by the user. Users should avoid entering personal or sensitive information that is not necessary for their scientific work.

Data stored by DinoCounter remains on the user's device unless the user deliberately exports, backs up, shares, or transfers that information.

The developer does not receive or have access to these locally stored scientific records.

## 3. Data export and scientific backups

DinoCounter provides features that allow users to export scientific data and create portable backups.

Depending on the feature used, exported information may include project metadata, sample information, counts, calculations, quality-control information, and other scientific records.

The user chooses where exported files or backups are saved or shared using Android's system interfaces.

Once a user exports or shares a file with another application, cloud-storage provider, messaging service, email service, institution, or other third party, the handling of that file is governed by the policies and practices of the selected destination.

DinoCounter does not automatically upload scientific data to a developer-operated server.

## 4. Android system backups

Depending on the user's Android version, device configuration, Google account settings, and backup preferences, Android may include application data in operating-system-level backups.

These backups are managed by Android, Google, the device manufacturer, or other system-level services according to the user's device and account settings.

The DinoCounter developer does not operate, access, or control those backup services and does not receive copies of data stored through Android system backup mechanisms.

Users who do not want device-level backups should review the backup settings provided by Android and their device manufacturer.

## 5. Internet access and external services

DinoCounter's core scientific counting and data-management functions are designed to operate offline.

Some optional actions may open an external website or application selected by the user.

For example, DinoCounter includes an optional **Support DinoCounter** feature that opens a PayPal page outside the application.

DinoCounter does not process payments and does not receive, store, or have access to payment card numbers, bank information, PayPal credentials, or other payment authentication information.

When users leave DinoCounter and interact with PayPal or another external service, that service may collect information according to its own privacy policy and terms.

Use of those external services is voluntary and is not required to access DinoCounter's scientific functionality.

## 6. Advertising

DinoCounter does not contain third-party advertising.

The application does not use advertising identifiers for personalized advertising or marketing.

## 7. Analytics and tracking

DinoCounter does not currently use third-party analytics or tracking technologies to monitor user behavior.

The developer does not create advertising profiles or sell user information.

## 8. Data sharing

DinoCounter does not sell user data.

The developer does not intentionally share locally stored scientific or personal information with third parties because that information is not transmitted to or collected by the developer.

Information may leave the device only when:

1. the user intentionally exports or shares data;
2. the user opens an external service such as PayPal;
3. the Android operating system performs a device-level backup according to the user's settings.

In these cases, the relevant third-party service or operating-system provider governs its own processing of information.

## 9. Data retention and deletion

Because DinoCounter's scientific data are primarily stored locally, users control the retention of their information.

Users can delete projects or other information using the application's available data-management functions, or remove locally stored application data through Android system settings.

Uninstalling DinoCounter normally removes locally stored application data from the device, subject to Android backup and restore behavior.

Before deleting application data or uninstalling DinoCounter, users are encouraged to create a scientific backup if they wish to preserve their records.

The developer cannot remotely retrieve, restore, or delete locally stored scientific data because those data are not maintained on developer-operated servers.

## 10. Data security

DinoCounter is designed as an offline-first scientific application in order to minimize unnecessary transfer of scientific information.

Users remain responsible for the security of their device, exported files, scientific backups, and any third-party storage locations they choose.

No method of electronic storage can be guaranteed to be completely secure.

## 11. Children's privacy

DinoCounter is designed as a scientific and professional tool and is not specifically designed for children.

The application does not knowingly collect personal information from children through developer-operated systems.

## 12. Changes to this Privacy Policy

This Privacy Policy may be updated if DinoCounter's functionality, data handling, third-party integrations, or legal requirements change.

Material changes will be reflected by updating the "Last updated" date on this page.

Users are encouraged to review this policy periodically.
